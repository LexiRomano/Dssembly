# Dssembly

## Introduction

Dssembly is an assembly language for the DGC-32 computer architecture.

## Usage

To build Dssembly, run:

```
bash$ ./make
```

Once built, use dssembly as such:

```
bash$ ./dssembly <inputFileName> <outputFileName>
```
